# 🖥️ 微信桌面自动化：特征驱动与会话分类识别规范 (WeChat GUI Automation Rules)

本文档记录微信 4.x（Qt5/Qt6 架构）桌面客户端的界面结构、交互特征与 Agent 鼠标/键盘控制准则，供自动化代聊 Agent 永久遵守。

---

## 1. 核心特征分类与点击目标准则

当通过搜索框（`Ctrl + F`）输入目标关键词后，微信 4.x 弹窗分为两大搜索形态：

### 形态 A：搜索真实联系人/好友（如：杨春、半夏、老兵、HR）
```text
┌─────────────────────────────────────────────────────────────────┐
│ 🔍 [搜索框] (例如输入: "杨春" 或 "半夏")                         │
├─────────────────────────────────────────────────────────────────┤
│ 🎯 [第 1 层：联系人] (Y 偏移: +70px ~ +110px)                   │
│    ✅ 唯一正确目标！带有好友真实头像与名称，点击进入 1v1 私聊。 │
├─────────────────────────────────────────────────────────────────┤
│ ❌ [第 2 层：搜索网络结果] (Y 偏移: +150px ~ +280px)              │
│    🚫 严禁点击！(搜狗网络搜词，点击会跳转外置网页)              │
├─────────────────────────────────────────────────────────────────┤
│ ❌ [第 3 层：群聊] (包含该联系人的群聊)                          │
│    🚫 严禁点击！(点击会进入群聊，非 1v1 私聊)                   │
└─────────────────────────────────────────────────────────────────┘
```

### 形态 B：搜索系统工具（如：文件传输助手）
```text
┌─────────────────────────────────────────────────────────────────┐
│ 🔍 [搜索框] (例如输入: "文件传输助手")                           │
├─────────────────────────────────────────────────────────────────┤
│ ❌ [第 1 层：搜索网络结果] (Y 偏移: +60px ~ +200px)               │
│    🚫 严禁点击！(5项搜狗网络搜词)                               │
├─────────────────────────────────────────────────────────────────┤
│ 🎯 [第 2 层：功能] (Y 偏移: +260px ~ +290px)                     │
│    ✅ 唯一正确目标！带有 🟢 绿色文件夹图标项，点击进入助手会话。│
├─────────────────────────────────────────────────────────────────┤
│ ❌ [第 3 层：收藏 / 聊天记录] (Y 偏移: +340px 及以下)           │
│    🚫 严禁点击！                                                │
└─────────────────────────────────────────────────────────────────┘
```

## 2. Agent 动态特征执行逻辑表

| 目标类型 | 关键词示例 | 匹配分类特征 | 过滤排除特征 | 动作细节 |
| :--- | :--- | :--- | :--- | :--- |
| **系统功能** | 文件传输助手 | 命中 **`功能`** 分类（🟢 绿色文件夹图标） | 排除“搜索网络结果”、“打开”、“已读”等 | 模拟点击【功能】项中心坐标 |
| **真实好友** | 杨春 / 半夏 / 老兵 / HR | 命中 **`联系人`** 分类（首项头像） | 排除“搜索网络结果”、“群聊” | 模拟点击【联系人】首项中心坐标 |
| **消息输入框** | 任意会话 | 位于右下区域 `EditControl` | 必须获取输入焦点 | 模拟鼠标点击获取焦点，粘贴文本并回车 |

## 3. 会话状态感知准则（绿色高亮判定）

* **活跃会话识别**：左侧联系人列表中，当前正在打开的会话项背景为 **🟩 绿色高亮**；
* **标题栏校验**：顶部中间区域（`left + width * 0.45, top + 35`）显示当前聊天对象的真实昵称/备注（如：`杨春`、`半夏`、`A安江老兵双彩`、`文件传输助手`）；
* **代聊防呆机制**：在执行回车发送前，Agent 必须校验输入框已获取焦点，确保消息 100% 注入正确的目标会话。
