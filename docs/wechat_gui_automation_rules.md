# 🖥️ 微信桌面自动化 UI 定位与控制持久化规范 (WeChat 4.x GUI Rules)

本文档记录微信 4.x（Qt5/Qt6 架构）桌面客户端的界面结构、交互特征与 Agent 鼠标/键盘控制准则，供自动化代聊 Agent 永久遵守。

---

## 1. 搜索框与下拉匹配项定位规则

当 Agent 模拟 `Ctrl + F` 或点击左上角搜索框（坐标 `left + width * 0.15, top + 35px`）输入关键词时，微信 4.x 会弹出垂直下拉菜单。**严禁直接点击前 1~5 项！**

### 弹窗区域分层特征（自上而下）：

```text
┌─────────────────────────────────────────────────────────────────┐
│ 🔍 [搜索框] (坐标: left + 15% 宽度, top + 35px)                  │
├─────────────────────────────────────────────────────────────────┤
│ ❌ [第 1 层：搜索网络结果] (Y 偏移: +60px ~ +200px)               │
│    包含 5 项搜狗网络搜词关键词。                                │
│    ⚠️ 严禁点击！点击会打开外置搜狗网页浏览器，不会打开微信聊天！  │
├─────────────────────────────────────────────────────────────────┤
│ 🎯 [第 2 层：功能 / 联系人] (Y 偏移: +260px ~ +300px)           │
│    ✅ 唯一正确点击目标！                                        │
│    - 文件传输助手：显示为【功能】分类下的 🟢 绿色文件夹图标项    │
│    - 好友/长辈/HR：显示为【联系人】分类下的好友头像项           │
├─────────────────────────────────────────────────────────────────┤
│ ❌ [第 3 层：收藏 / 聊天记录] (Y 偏移: +340px 及以下)           │
│    ⚠️ 严禁点击！点击会进入历史收藏备忘录，不会进入当前聊天会话。│
└─────────────────────────────────────────────────────────────────┘
```

## 2. Agent 鼠标点击精确坐标基准

在微信主窗口矩形区域 `(left, top, right, bottom)` 基础上：

| 交互目标 | X 坐标计算公式 | Y 坐标计算公式 | 说明 |
| :--- | :--- | :--- | :--- |
| **顶部搜索框** | `left + width * 0.15` | `top + 35` | 激活搜索 |
| **【功能】文件传输助手** | `left + width * 0.15` | **`top + 280`** | **精确命中绿色文件夹图标** |
| **【联系人】普通好友** | `left + width * 0.15` | `top + 270` | 精确命中联系人分类项 |
| **右侧聊天输入框** | `left + width * 0.65` | `bottom - height * 0.15` | 模拟聚焦并粘贴大模型回复 |

## 3. 会话状态感知准则（绿色高亮判定）

* **活跃会话识别**：左侧联系人列表中，当前正在打开的会话项背景为 **🟩 绿色高亮**；
* **标题栏校验**：顶部中间区域（`left + width * 0.45, top + 35`）显示当前聊天对象的真实昵称/备注（如：`杨春`、`半夏`、`A安江老兵双彩`、`文件传输助手`）；
* **代聊防呆机制**：在执行回车发送前，Agent 必须校验输入框已获取焦点，确保消息 100% 注入正确的目标会话。

---

## 4. 大模型人设映射规则

所有消息内容必须调用本地 NewAPI（`http://127.0.0.1:3000/v1`）中的 **DeepSeek-V4-Flash** 模型，并根据聊天对象动态切换第一人称语气：

1. **母亲（半夏）**：孝顺听话、亲切体贴、随叫随到（如守店、搞饭、跑腿）；
2. **长辈（老兵叔叔等）**：尊敬礼貌、真诚热情、懂事得体；
3. **HR / 面试官**：专业敬业、强调统招本科学历与区块链工程背景、随时可到岗；
4. **文件传输助手**：自动化连通测试与状态上报。
