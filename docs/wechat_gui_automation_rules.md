# 🖥️ 微信桌面自动化：特征驱动与会话双重识别规范 (WeChat GUI Automation Rules)

> [!IMPORTANT]
> **铁律原则**：严禁盲目发送！在向任何聊天窗口输入文字或敲击回车前，Agent **必须严格执行【双重会话校验法则】**，确保 100% 处于正确目标联系人界面，彻底杜绝串台误发。

---

## 1. 当前聊天界面【双重识别与校验法则】

微信 4.x 提供了两个互为印证的会话激活特征，Agent 在操作过程中**必须同时感知与校验**：

```text
┌────────────────────────────────────────┬────────────────────────────────────────┐
│ 🔍 搜索框                               │ 🎯【校验特征 B：顶部标题栏名称】        │
├────────────────────────────────────────┤   半夏                 (··· 📞 💬)      │
│ 📱 公众号                              ├────────────────────────────────────────┤
│ 🤖 微信ClawBot                         │                                        │
├────────────────────────────────────────┤                                        │
│ 🎯【校验特征 A：左侧绿色高亮背景】      │           （当前聊天消息区）            │
│   🟩 [红枫头像]  半夏                  │                                        │
├────────────────────────────────────────┤                                        │
│ 👤 A金...                              │                                        │
│ 👤 金牌护肤...                         ├────────────────────────────────────────┤
│ 👥 佩奇一家                            │ ⌨️ [输入框区]                          │
└────────────────────────────────────────┴────────────────────────────────────────┘
```

### 双重校验判定矩阵：

| 校验源 | 界面物理位置 | 判定条件 | 核心作用 |
| :--- | :--- | :--- | :--- |
| **特征 A：左侧绿色高亮** | 左侧最近会话列表栏 | 目标条目（如【半夏】）背景为 **🟩 墨绿色高亮（Green Active Block）** | 视觉确认焦点已被激活在该联系人条目 |
| **特征 B：顶部标题栏名称** | 右侧聊天区左上方导航栏 | 文本控件显式展示目标大字昵称（如：`半夏`） | 语义确认当前主屏渲染的内容属于该联系人 |

* **执行准则**：只有特征 A 与特征 B 校验一致时，才允许模拟鼠标点击输入框打字回车！

## 2. 搜索框下拉特征甄别规则

当通过搜索框（`Ctrl + F`）输入目标关键词后，微信 4.x 弹窗分为两大搜索形态：

### 形态 A：搜索真实联系人/好友（如：杨春、半夏、老兵、HR）
* **🎯【唯一正确点击目标】**：最顶部的 **【联系人】** 分类第 1 项（带好友真实头像）；
* **🚫【严格排除】**：中部的 `搜索网络结果`（网络搜词）与下部的 `群聊`（包含该人的群）。

### 形态 B：搜索系统工具（如：文件传输助手）
* **🎯【唯一正确点击目标】**：中部的 **【功能】** 分类项（带 🟢 绿色文件夹图标）；
* **🚫【严格排除】**：顶部的 `搜索网络结果`（搜狗搜词）与底部的 `收藏`（聊天记录）。

## 3. 多会话全局感知与防串台机制

当用户正在查看其他群聊（如公考群）或好友（如濠哥）时：
1. **静默守护**：Agent 在后台实时检测左侧列表中目标联系人（如【半夏】）的未读红点与最新预览变化；
2. **自动切回**：一旦目标联系人发来新消息，Agent 自动切换会话 ➔ **通过双重校验（左侧变绿 + 顶部变半夏）** ➔ DeepSeek 大脑生成高情商回复 ➔ 自动秒回！
3. **零主动骚扰**：对方不发消息时，AI 绝不主动发送任何干扰内容。
